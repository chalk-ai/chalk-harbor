# Installations Larkspur could not complete

If the crew delivered an item but **could not complete its installation because of Larkspur** (missing
parts or connectors, wrong tools, crew ran out of time):
1. Refund **that item's installation fee** (reason `installation_fee`) — the customer has waited and
   will still get the installation for free.
2. Dispatch a return visit with category `installation` on a day the customer can make.
3. Schedule a follow-up after the visit (KB-113).

If the installation could not be completed because of the home (no outlet of the right type, no gas
shut-off valve, code issues), there is no refund; the customer must fix the site first.
